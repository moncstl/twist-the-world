# 세상을비틀다 — 시장 레이더 · 2주 롱숏 & 타점 보드

코스피 **2주 롱·숏 시나리오 일정표**, **코스피100 선점 TOP 5 매수 타점**, **섹터 자금이동**,
그리고 시황·종목 영상 허브를 한 장에 모아 **매 거래일 갱신**하는 공개 대시보드입니다.

- 공개 주소: <https://moncstl.github.io/twist-the-world/>
- 정적 사이트입니다(서버·DB 없음). 모든 수치는 페이지를 만들 때의 시점 값이며 화면에 **기준 시점**을 함께 적습니다.
- 앱으로 설치할 수 있습니다(PWA, `manifest.webmanifest`).

## 갱신

- 거래일 장 마감 후 자동 재생성되어 이 저장소에 반영됩니다.
- 데이터 출처: 한국거래소 일별 지수, 네이버 금융(지수), Yahoo Finance(선물·변동성), 공개 공시·보도, 자체 시나리오·스크리너 엔진.

- 이 사이트는 **공개 시장 데이터만** 사용합니다. 개인 계좌·자금·매매 내역·가족 일정은 포함하지 않습니다.
- 방문자 추적 스크립트·광고를 넣지 않습니다.

## 투자 유의

이 페이지의 모든 수치와 시나리오는 공개 정보를 정리한 **정보·해설**이며 특정 종목의 매수·매도를
권유하지 않습니다. 가격·지표는 기준 시점 이후 달라질 수 있고, 과거 적중이 미래 수익을 보장하지
않습니다. 투자 판단과 책임은 투자자 본인에게 있습니다.
